# CinéVault Project Plan

## Overview

CinéVault is a movie discovery platform that allows users to explore movies, discover upcoming releases, and manage their personal watchlist.

## Main Features

### User Account
- Register/Login
- User profile
- Personal watchlist

### Movie Library
- Browse movies
- View movie details
- See actors, directors, genres, ratings
- Add movies to watchlist

### Cinema Section
- Currently playing movies
- Upcoming movies

### AI Movie Assistant
- Help users find movies using natural language descriptions
- Recommend movies based on user requests

## Technologies

Frontend:
React + Vite

Backend:
Spring Boot

Database:
PostgreSQL

External APIs:
TMDB API
